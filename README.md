# विष्णु अवतारंम (Vishnu Avatarm)

भगवान विष्णु के 24 अवतारों की पूरी ऐप।

## GitHub Pages पर चलाने का तरीका

1. नया GitHub repository बनाएँ (उदा. `vishnu-avatarm`)
2. इस पूरे फोल्डर की सामग्री अपलोड करें:
   - `index.html`
   - `images/` फोल्डर (सभी चित्र)
   - `README.md`
3. Repo → **Settings** → **Pages**
4. Source: **Deploy from a branch** → Branch: `main` → Folder: `/ (root)` → Save
5. कुछ मिनट बाद URL खुलेगा:
   `https://YOUR_USERNAME.github.io/vishnu-avatarm/`

## लोकल उपयोग

`index.html` को डबल-क्लिक करके किसी भी ब्राउज़र में खोलें।  
`images` फोल्डर `index.html` के साथ ही होना चाहिए।

## नोट

- सभी चित्र `images/` फोल्डर में हैं (base64 एम्बेड नहीं) — इसलिए GitHub पर सफेद स्क्रीन नहीं आएगी।
- मोबाइल और डेस्कटॉप दोनों पर काम करता है।
